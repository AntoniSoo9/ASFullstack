
# 0.6: New note in Single page app diagram

```mermaid
sequenceDiagram
    participant browser
    participant server

    Note over browser: User writes a note and clicks Save

    Note right of browser: JavaScript prevents the default form submission
    Note right of browser: JavaScript creates a note object with content and date
    Note right of browser: The new note is added to the local notes array
    Note right of browser: JavaScript renders the updated notes list

    browser->>server: POST /exampleapp/new_note_spa
    Note right of browser: Request body contains the note as JSON
    activate server
    Note right of server: Server saves the new note
    server-->>browser: HTTP 201 Created
    deactivate server

    Note over browser: The updated note is already visible
    Note over browser: The page is not reloaded
```
